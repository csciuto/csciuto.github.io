# corey.sciu.to

Personal site for Corey Sciuto, served by GitHub Pages at https://corey.sciu.to.

- `/` is the About page (`index.html`, adapted from Dinesh Pandiyan's MIT-licensed Dev Landing Page).
- `/projects/` lists my apps. It is generated by `scripts/build_projects.py` and is not committed.

## How apps get published

Each app lives in its own repo with GitHub Pages turned on, so GitHub serves it at
`https://corey.sciu.to/<repo>/` automatically. Nothing in this repo needs to change.

To list an app on the projects page, give its repo:
1. a description,
2. a homepage URL (the live app), and
3. the `corey-app` topic.

The **Deploy site** workflow rebuilds the projects page on every push and once a day.
Run it manually from the Actions tab (or `gh workflow run deploy.yml`) to update it immediately.

The baby announcement in `babyannouncement/` is kept here directly. Its README explains how it works.
