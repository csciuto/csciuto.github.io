# corey.sciu.to

The personal site: the About page at `/`, the generated projects page at `/projects/`, and the tooling that
starts and lists apps (`scripts/new-app`, `scripts/build_projects.py`). See README.md for how it works.

## Rules

- **`/projects/` links to the About page (as "Corey Sciuto"); the About page does not link to `/projects/`.**
  Don't add that direction unless asked. Honor exclusions like this
  literally, including in generated pages and footers.
- Apps live in their own repos and follow `STANDARDS.md` in
  [csciuto/app-template](https://github.com/csciuto/app-template). Change shared app conventions there, not
  here.
- Don't pin repos on the GitHub profile. Keep LinkedIn as the profile's website.
- Some apps are deliberately unlisted (no `corey-app` topic). Don't list one without being asked.
- Commit and push freely once checks pass; ask before deleting repos, force-pushing or rewriting history.
